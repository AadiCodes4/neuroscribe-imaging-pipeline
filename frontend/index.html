NeuroScribe

Multimodal medical-imaging segmentation & interpretability pipeline — educational demo

Not a medical device. This entire project — model, training data, and this UI — operates only on procedurally generated synthetic images meant to loosely resemble a 2D scan slice with lesion-like blobs. No real patient data or real MRI/CT scans are used anywhere. This is a portfolio / educational demo, not a clinical or diagnostic tool, and must never be used to make real medical decisions.
NeuroScribe frontend — a static single-file React app (loaded via CDN, no build step required).
